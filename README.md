# Remote-Car-distance-time
This simulates a car moving towards and away from Emile while showing the corresponding distance vs time graph.

The car's motion on the road and the point on the graph are synchonized in real time.

📌Features
-🧍‍♀️ Emile fixed on the left side of the road
-🚕 Car moves according to predefined distance-time data points
-📉 Distance-Time graph using HTML5 Canvas
-🔴 Moving marker on the graph to show (t, d) position
-▶⏸🔄 Controls: Play, Pause, Reset

⚙Tech Stacks
- HTML -> Page structure
- CSS  -> Styling
- JavaScript -> Logic, Animation & Synchronization


How to Run
1. Download or clone this Repository
2. Open 'index.html' in any modern browser
3. Click 'Play' to start animation
